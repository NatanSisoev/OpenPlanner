# Main ideas

## Core implementations
- **Plans as nodes**: most abstract and visually clear representation of a plan. 

- **State as a color**: each node will have a color depending on its state:
    1. green: has already executed succesfully.
    2. orange: currently executing.
    3. red: not executing at all.

- **Tasks**: When clicking on a node, show the tasks with checkboxes to select which ones want to be executed.
